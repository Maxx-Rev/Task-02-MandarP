Expense Tracker
A simple Python command-line application that helps users keep track of their expenses. Users can continuously enter expense amounts, and the program automatically calculates the running total until they choose to quit.

Features
- Add multiple expenses
- Real-time total expense calculation
- Input validation using exception handling
- Simple and user-friendly command-line interface
- Beginner-friendly Python project

How It Works
1. The program starts by displaying a welcome message.
2. Users enter expense amounts one at a time.
3. Each valid expense is added to the total.
4. The current total is displayed after every entry.
5. Type "quit" to stop entering expenses and view the final total spent.

Requirements
- Python 3.14.3

No external libraries are required.
